# Decodificador Morse

Aplicação web em Flask para codificar texto em código Morse e decodificar Morse em texto.

## Início rápido

No PowerShell, dentro da pasta do projeto:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r require.txt
python start.py
```

Abra `http://127.0.0.1:5000` no navegador.

Para separar palavras ao escrever em Morse, use `/`:

```text
.... --- .-.. .- / -- ..- -. -.. ---
```
